# Radar Puls Web

Radar Puls je web platforma povezana sa mobilnom aplikacijom koja prikazuje:

- lokacije policije
- radare
- kontrole
- incidente na putu

Cilj platforme je da vozači mogu da dele informacije u realnom vremenu.

---

# MVP verzija

Prva verzija nema backend.

Podaci o lokacijama dolaze iz statičnog JSON fajla.

Kasnije će biti dodati:

- user reporting
- reputacija korisnika
- real-time mapa
- backend API
